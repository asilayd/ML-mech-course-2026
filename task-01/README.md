# Wave Farm Power Prediction

Предсказание суммарной поглощённой мощности волновой
фермы по геометрии размещения 16 преобразователей.

## Исследовательский вопрос

Какие геометрические характеристики массива устойчиво
связаны с суммарной мощностью и переносятся между
волновыми сценариями?

## Данные

- Sydney
- Adelaide
- Perth
- Tasmania

Целевая переменная: `Powerall`.

Переменные `P1`–`P16` исключены из входных признаков
во избежание утечки целевой информации.

## Методология

- Базовая модель
- Метод наименьших квадратов
- Физически мотивированная линейная модель
- Полиномиальная регрессия
- Ridge, Lasso, ElasticNet
- Анализ устойчивости коэффициентов
- Проверка на отложенном волновом сценарии
